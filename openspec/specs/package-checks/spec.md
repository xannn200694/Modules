# package-checks Specification

## Purpose

Задаёт, как в WSL через Compose прогоняются phpcs, phpstan и phpunit для этого пакета и чем заканчивается успешный прогон.

## Requirements

### Requirement: Запуск проверок

Проверки SHALL выполняться командами Compose в среде PHP 8.5 и MUST NOT публиковать сетевой порт. Успешная проверка SHALL завершаться кодом 0.

#### Scenario: Успешный запуск

- **WHEN** проверка запущена командой Compose и нарушений нет
- **THEN** процесс завершается с кодом 0 и не открывает порт

#### Scenario: Есть нарушение

- **WHEN** проверка запущена командой Compose и находит нарушение
- **THEN** процесс завершается с ненулевым кодом

### Requirement: Соответствие PSR-12

phpcs SHALL проверять исходники пакета на соответствие PSR-12.

#### Scenario: Исходники соответствуют PSR-12

- **WHEN** запускается phpcs и исходники соответствуют PSR-12
- **THEN** phpcs завершается с кодом 0

#### Scenario: Нарушение PSR-12

- **WHEN** запускается phpcs и исходник нарушает PSR-12
- **THEN** phpcs завершается с ненулевым кодом

### Requirement: Статический анализ

phpstan SHALL анализировать каталог исходников пакета на уровне 5.

#### Scenario: Анализ без ошибок

- **WHEN** запускается phpstan и ошибок уровня 5 нет
- **THEN** phpstan завершается с кодом 0

#### Scenario: Анализ нашёл ошибку

- **WHEN** запускается phpstan и ошибка уровня 5 есть
- **THEN** phpstan завершается с ненулевым кодом

### Requirement: Тесты загрузки модулей

phpunit SHALL поднимать пакет внутри тестового процесса и проверять сценарии опубликованной спецификации `module-boot`. Тестам MUST NOT требоваться каркас приложения Laravel в репозитории.

#### Scenario: Сценарии module-boot проходят

- **WHEN** запускается phpunit и сценарии `module-boot` соблюдены
- **THEN** phpunit завершается с кодом 0

#### Scenario: Сценарий module-boot нарушен

- **WHEN** запускается phpunit и сценарий `module-boot` не соблюдён
- **THEN** phpunit завершается с ненулевым кодом
